# Eval cases

Each file here pins a change to Cruze to the evidence that prompted it: journal entries from a project's `cruze feedback export`, found by the `cruze-retro` maintainer skill. The format is in `.agents/skills/cruze-retro/eval-cases.md`.

The first cases, dated 2026-09-28, come from the retro on the mw-configuration-service project's feedback bundle and a review of its code. Cases whose check is a test name it; the others are fixture runs still to be run.
