# Realign notes: 0.0.2

## Existing code

### test-placement: Rust tests that outgrow their file live in tests/
- Applies to: existing code
- Rule: `.agents/skills/cruze-hexagonal-design/languages/rust.md`, "Dependencies and tooling"
- Detect: check:test-placement
- Migrate: move `src/<module>/tests.rs` and `src/<module>/tests/*.rs` to the crate's `tests/<module>.rs`, or `tests/<module>/main.rs` with one file per topic, driving the public API. A test whose private seam is the contract, such as a filesystem trait a crash test injects, stays, listed under `check.exceptions` with that reason.

### readme-overview: The README says what the project is
- Applies to: existing code
- Rule: `.agents/skills/cruze-envision/project.md`, step 9
- Detect: validate:readme-overview
- Migrate: write one paragraph under the README's title from the vision's Problem, Users and Goals, ending with a link to `docs/vision.md`.

### feature-size: A feature has at most 6 changes
- Applies to: existing code
- Rule: `.agents/skills/cruze-architect/feature.md`, step 12
- Detect: validate:feature-size
- Migrate: only for features still in progress. Keep the changes that have landed or started, and move the rest into a new feature with `cruze features add`, through `rethink` at feature level.

### module-paths: Every file a task writes is inside a module's Path
- Applies to: existing code
- Rule: `.agents/skills/cruze-plan/tasks.md`, step 6
- Detect: validate:outside-module-map
- Migrate: only for changes still being planned or built. Add the file to its owner's `Path` through `rethink` at architecture level, or move the file.

### error-types: Error types exist only where callers handle their cases differently
- Applies to: existing code
- Rule: `.agents/skills/cruze-hexagonal-design/SKILL.md`, "Representations and errors"
- Ask: Does any error type copy another's variants, differ from another only in its name, or carry a case that every caller rules out, such as with `unreachable!` or `expect`? Does a use case define its own error when it only passes a domain error through?
- Migrate: return or wrap the domain error in one case, merge similar failures into one type with the difference as a field, and narrow return types. Keep wire codes, messages and exit statuses unchanged. When `docs/architecture.md` names the error types, rethink at architecture level before the prefactor.

### shared-test-support: Tests share fixtures and harnesses
- Applies to: existing code
- Rule: `.agents/skills/cruze-behavioural-testing/SKILL.md`, "Test support"
- Ask: Do test files define helpers, fixtures or harnesses that another test file or the test support module already has, or share code across crates with `#[path]` includes?
- Migrate: move each shared helper into the test support module, and in a Rust workspace into one dev-only test-support crate. Replace the copies with uses of it.
