# Realign notes: 0.0.8

## Existing code

### module-path-glob: A module's Path is a directory or a file, never a glob
- Applies to: existing code
- Rule: `.agents/skills/cruze-formats/reference/architecture.md`, "Element facts"
- Detect: validate:module-path-glob
- Migrate: replace each glob in a `MOD` element's `Path` with the directories it meant, each ending in `/`, or the files, through `rethink` at architecture level.

### budget-not-a-shape: No code is bent to fit a file budget
- Applies to: existing code
- Rule: `.agents/skills/cruze-hexagonal-design/SKILL.md`, "Many small modules"
- Ask: is any code shaped to stay under `check.max_lines` or `check.max_types`, such as a type alias, a string where an error type belongs, merged types, a function placed away from its owner, or Rust domain tests moved out of their file only for its length?
- Migrate: write the code as it would be with no budget. Split a file that then passes its budget along a second responsibility, or list it under `check.exceptions` with the reason it has one. Rust domain tests may move back inline, since their `#[cfg(test)]` modules no longer count.

### no-dependency-workarounds: No code works around a dependency or feature nobody asked for
- Applies to: existing code
- Rule: `.agents/skills/cruze-dependency-approval/SKILL.md`, "Weighing"
- Ask: does any code hand-write, shell out for, or use a less idiomatic construct for something a dependency or a feature of an approved dependency does cleanly, where the design or a deviation gives avoiding the dependency as the reason?
- Migrate: ask the user for the dependency as the dependency-approval skill says, then replace the workaround through `rethink` at feature level.
