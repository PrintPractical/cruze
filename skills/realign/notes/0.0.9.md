# Realign notes: 0.0.9

## Existing code

### budget-backstop: File budgets are a backstop, and files split by responsibility, never by length
- Applies to: existing code
- Rule: `.agents/skills/cruze-hexagonal-design/SKILL.md`, "Many small modules"
- Ask: does `.cruze/config.yaml` still set the old defaults, `check.max_lines: 250` and `check.max_types: 5`? Is any `check.exceptions` entry, or any split of one owner across files, there only to meet them?
- Migrate: raise the budgets to `max_lines: 600` and `max_types: 12`, unless the user chose the old ones, and remove each exception whose file is now within budget. A split made only for length, whose files share one responsibility, merges back in a prefactor; waive it when the files read well apart.

### flow-control-review: A design says how its work flows, waits and recovers
- Applies to: existing code
- Rule: `.agents/skills/cruze-roles/design-rubric.md`, "Design rubric", item 11
- Ask: for each feature in flight, does its design leave out any check in rubric item 11 that a scenario or an `XC` rule depends on, such as what a sender does when a queue is full, or what happens when a reconnect fails?
- Migrate: settle each gap through `rethink` at feature level before the feature's next change is planned. Code a landed change built goes to a prefactor.

### references: External specifications the design must follow are listed under references
- Applies to: existing code
- Rule: `.agents/skills/cruze-formats/reference/config.md`, "references"
- Ask: does the project rely on an external document it must comply with, such as a protocol specification in the repository, that `references:` in `.cruze/config.yaml` doesn't list?
- Migrate: list each under `references:` with its path and what it governs, as the user confirms.
