# Realign notes: 0.0.10

## Existing code

### decision-citations-docs: Living docs and deltas cite a decision by number only where it is recorded
- Applies to: existing code
- Rule: `.agents/skills/cruze-formats/SKILL.md`, "Decisions"
- Detect: validate:decision-citation
- Migrate: in a prefactor, rewrite each citation the rule reports in `docs/`: write what the decision settled into the element or sentence, reading it from the archived feature's `## Settled decisions` under `.cruze/archive/`, or cite the ADR that records it. A feature in flight fixes its own delta through `rethink` before its next approval, since `cruze approve` refuses a delta that cites one.

### decision-citations-code: Code comments cite no decision by number
- Applies to: existing code
- Rule: `.agents/skills/cruze-formats/SKILL.md`, "Decisions"
- Detect: check:decision-citation
- Migrate: in a prefactor, replace each citation `cruze check` reports with what was decided, in a few words, or with the element or ADR ID that holds it. Delete one that adds nothing to what the code already says.

### pitfalls-to-cruze: Known pitfalls hold only lessons about the project
- Applies to: existing code
- Rule: `.agents/skills/cruze-land/SKILL.md`, "Landing a change", step 7
- Ask: which lines under `## Known pitfalls` in `AGENTS.md` are about how Cruze's deltas, plans, tasks, test plans or reviews are written, or about practice that holds in any project in the language, rather than this product's domain or code?
- Migrate: record each such line with `cruze journal add lesson --set summary=<text> --set instead=<text> --set step=<step>`, so `cruze feedback export` carries it to Cruze, then remove it from `AGENTS.md`.
